# Кириллица на английском клиенте

Квадраты вместо русских букв обычно означают, что выбранный шрифт не содержит
нужных символов. DiscodicXP включает Fira Sans Regular с кириллицей и использует
его во встроенных темах V1/V2, включая Forever, текст шагов и вкладки игроков.
Для пользовательской темы можно указать путь
`Interface/AddOns/DiscodicXP/Fonts/FiraSans-Regular.ttf` в настройках шрифта.

## Чат и экран выбора персонажа

Шрифт темы аддона не исправляет весь клиент. DiscodicXP не меняет глобальные
шрифты; на экране выбора персонажа аддоны ещё не загружены.

Сначала проверьте русский текст после полного перезапуска игры с отключёнными
аддонами. Если квадраты остаются на экране выбора персонажа и в чате, проблема
в клиенте или его пользовательских шрифтах. Если только в чате и только с
аддонами — проверьте шрифт аддона, который оформляет чат: он может использовать
собственный файл вместо стандартного.

Для проверки стандартных шрифтов подготовлен отдельный архив
[DiscodicXP-English-client-fonts.zip](https://github.com/Ishimitsu14/DiscodicXP-WoW-Forever/releases/download/v0.4.2/DiscodicXP-English-client-fonts.zip). Он содержит Fira Sans под именами
стандартных латинских и кириллических файлов WoW, лицензию и эту инструкцию.
Пакет не требует установки DiscodicXP и не содержит гайдов.

1. Полностью закройте WoW.
2. Сохраните резервную копию существующей папки `Fonts` рядом с исполняемым
   файлом именно того клиента, который запускаете. Не удаляйте её содержимое.
3. Скопируйте файлы из папки `Fonts` архива в эту папку клиента. Это папка
   рядом с `WowB.exe` или `Wow.exe`, а не `Interface/AddOns`.
4. Запустите клиент заново и проверьте русские имена на экране выбора персонажа,
   затем русский чат и DiscodicXP. Одного `/reload` для этой проверки недостаточно.

Замена изменяет начертание стандартного текста на Fira Sans. Для отмены закройте
игру, удалите только добавленные из архива TTF-файлы и восстановите одноимённые
файлы из резервной копии. Остальные файлы `Fonts` сохраняются.

На проблемном английском клиенте пакет ещё нужно проверить. Если он не
подхватывает файлы или квадраты остаются без аддонов, потребуется восстановление
ресурсов клиента; изменение Lua аддона не исправит экран выбора персонажа.
