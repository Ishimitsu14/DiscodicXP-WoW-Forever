# DiscodicXP для WoW Forever

Приоритет пользователя: купленный маршрут должен работать без проверки BattleTag.

## Основа

Отдельный аддон на совместимом движке установленного RestedXP 4.11.23.
Сохраняются парсер маршрутов, условия класса и расы, отслеживание заданий,
стрелка, карта и прогресс. Переписывать их до проверки всего платного маршрута
рискованно: у Forever свои координаты, задания и ветвления.

Исходный RXPGuides не меняется. Сборщик создаёт папку dist/DiscodicXP с отдельными
глобальными именами, событиями, командами и SavedVariables. Условия лицензии
исходного движка и лицензии библиотек сохраняются.

## Загрузка купленного маршрута

Локальный сборщик читает приложенный файл, раскрывает контейнер по алгоритму
исходного импортера, проверяет контрольные суммы и число разделов. Идентификатор
из имени исходного файла в готовый аддон не записывается. Производный ключ
включён в локальную сборку для последующего импорта обновлений. Маршруты
первого комплекта загружаются как встроенные текстовые гайды.

Игровой загрузчик и кэш не обращаются к Battle.net. Кэш использует постоянную
версию формата, а не идентификатор аккаунта.

В версии 0.2.0 команда `/dxp import` открывает окно вставки текста файла.
Используется существующий буферизированный EditBox движка, чтобы не выводить
сотни тысяч символов в игровой интерфейс. Сначала контейнер расшифровывается
и проверяется целиком; затем парсер обрабатывает разделы и готовит сжатый кэш.
До завершения этой фазы база маршрутов не меняется. Между порциями данных и
разделами управление возвращается игре через корутину.

Коммит заменяет кэш для совпадающих ключей без дубликатов, пропускает более
старые версии и восстанавливает прежние таблицы при ошибке добавления. Прогресс
не сбрасывается. Импортированные разделы имеют приоритет при последующей
загрузке встроенного комплекта; текущий раздел перечитывается с keepStep.

Для файла с другим ключом можно локально вставить исходное имя файла.
Оно используется только для получения ключа, не сохраняется в базе и
очищается из поля после успешного импорта. Ключ последнего успешного импорта
сохраняется в DXPData; API аккаунта не вызываются. Отмена до коммита, ошибка
парсинга или начало боя оставляют прежние маршруты на месте.

## Интерфейс

Русские элементы управления, отдельное название DiscodicXP, тёмный фон,
золотые границы и бордовые акценты Орды. Основа — существующие компоненты
движка, чтобы сохранить перенос окна, изменение размеров, меню и клики шагов.

Текст купленного маршрута сохраняется без изменения логики. Перевод интерфейса
не означает полный литературный перевод всех авторских пояснений маршрута.

В 0.3.0 добавлены отдельный справочник названий QuestieDB Forever и NameResolver.
Русские имена клиента имеют приоритет, затем используются сохранённый кэш,
таблица имён движка и справочник. Английское имя маршрута проверяется перед
подстановкой записи базы. Неполученное название остаётся исходным именем,
а активные цели повторно запрашивают данные с ограниченным числом попыток.
ID сохраняются отдельно. Скрытая подсказка поиска NPC не изменяет видимую
подсказку игрока; изменение защищённых кнопок откладывается до окончания боя.

Команда names:update получает имена вне игры из фиксированной ревизии
QuestieDB, проверяет хеши исходников и атомарно обновляет JSON-справочник.
Lua из внешних источников разбирается как данные и не исполняется.
Сборщик переносит справочник в аддон; HTTP из игрового Lua не используется.

## Проверка

Автоматически: контейнер и контрольные суммы, отсутствие идентификатора в
сборке, отсутствие игровых вызовов Battle.net, изоляция пространств имён,
граф TOC/XML, синтаксис Lua 5.1 и проверки загрузчика в Lua VM без BNGetInfo.

В игре: включение аддона, старт подходящего Орде раздела, принятие и сдача
задания, стрелка и сохранение прогресса после /reload. Этот этап нельзя
подтвердить статическим анализом.
