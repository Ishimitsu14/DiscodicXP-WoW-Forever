# DiscordikXP для WoW Forever

Приоритет пользователя: купленный маршрут должен работать без проверки BattleTag.

## Основа

Отдельный аддон на совместимом движке установленного RestedXP 4.11.23.
Сохраняются парсер маршрутов, условия класса и расы, отслеживание заданий,
стрелка, карта и прогресс. Переписывать их до проверки всего платного маршрута
рискованно: у Forever свои координаты, задания и ветвления.

Исходный RXPGuides не меняется. Сборщик создаёт папку dist/DiscodicXP с отдельными
глобальными именами, событиями, командами и SavedVariables. Условия лицензии
исходного движка и лицензии библиотек сохраняются.

## Загрузка маршрутов с сервера

С версии 0.5.1 сборщик не принимает файл гайдов и не включает маршруты или
ключ расшифровки в публичный архив. Из исходного движка также не копируются
списки встроенных маршрутов. В TOC заранее объявлен пустой
`UserGuides/ForeverHorde.lua`, поэтому после первой установки новые пакеты
можно применять через `/reload`.

Админка в отдельном серверном репозитории принимает исходный `.txt`, проверяет
контейнер и сохраняет версию пакета. Лаунчер получает его по ключу устройства,
проверяет размер и SHA-256, формирует вызовы RegisterGuide со строковыми
литералами и заменяет файл с резервной копией. Публикация кода аддона не пишет
в базу гайдов админки. Прямых HTTP-запросов из игрового Lua нет.

Манифест содержит `guideUpdates: 1`: при обновлении аддона лаунчер сохраняет
файл серверных гайдов из совместимой установленной версии. Локальный
`tools/install.ps1 -Update` использует тот же признак. Чистая установка
остаётся без маршрутов до первой загрузки кнопкой «Обновить гайды».

`GuideUpdates.lua` отключает ручной импорт и загрузку старых импортированных
гайдов из SavedVariables. Прежние данные сохраняются в `legacyGuides`, но
больше не перекрывают серверный файл. При изменении digest пакета очищаются
метаданные и кэш неподходящих разделов; текущий шаг и прогресс сохраняются.
Игровой загрузчик не зависит от Battle.net или идентификатора аккаунта.

## Интерфейс

Элементы управления подстраиваются под язык клиента, отображаемое название
DiscordikXP, тёмный фон,
золотые границы и бордовые акценты Орды. Основа — существующие компоненты
движка, чтобы сохранить перенос окна, изменение размеров, меню и клики шагов.

Текст купленного маршрута сохраняется без изменения логики. Перевод интерфейса
не означает полный литературный перевод всех авторских пояснений маршрута.

С 0.4.3 сборщик сохраняет все переводы движка и выбор AceLocale по `GetLocale()`.
Собственные окна и сообщения имеют английские исходные строки и русский
перевод для `ruRU`. Русские названия зон и справочник не навязываются другим
клиентам. Идентичность папки `DiscodicXP`, SavedVariables и ключей маршрутов
сохранена; новое имя применяется к отображаемому тексту.

Переключатель Hide NPC Selection window рядом с Hide Active Item window
и `/dxp npc on|off` используют существующий
параметр профиля `enableTargetFrame`. Галочка скрытия показывает обратное
значение этого параметра, сохраняя совместимость с настройками целей.
Обновление защищённого окна откладывается
до `PLAYER_REGEN_ENABLED`, если настройка изменена в бою. Отключённое окно
скрывается и при обычном обновлении списка целей, не затрагивая текущие шаги.

В 0.3.0 добавлены отдельный справочник названий QuestieDB Forever и NameResolver.
Русские имена клиента имеют приоритет, затем используются сохранённый кэш,
таблица имён движка и справочник. Английское имя маршрута проверяется перед
подстановкой записи базы. Неполученное название остаётся исходным именем,
а активные цели повторно запрашивают данные с ограниченным числом попыток.
ID сохраняются отдельно. Скрытая подсказка поиска NPC не изменяет видимую
подсказку игрока; изменение защищённых кнопок откладывается до окончания боя.

Команда names:update получает имена вне игры из фиксированной ревизии
QuestieDB, проверяет хеши исходников и атомарно обновляет JSON-справочник.
Lua из внешних источников разбирается как данные и не исполняется.
Сборщик переносит справочник в аддон; HTTP из игрового Lua не используется.

## Проверка

Автоматически: отсутствие маршрутов и ключа импорта в публичной сборке,
отсутствие игровых вызовов Battle.net, изоляция пространств имён,
граф TOC/XML, синтаксис Lua 5.1 и проверки загрузчика в Lua VM без BNGetInfo.

В игре: включение аддона, старт подходящего Орде раздела, принятие и сдача
задания, стрелка и сохранение прогресса после /reload. Этот этап нельзя
подтвердить статическим анализом.
