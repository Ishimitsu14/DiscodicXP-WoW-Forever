# Русские названия NPC и заданий

В игре названия берутся из клиента, затем из сохранённого кэша и встроенного
русского справочника. Исходное имя из маршрута остаётся запасным вариантом.
Имена из клиента имеют приоритет над справочником. Кэш разделён по игре и языку.

Справочник содержит только названия NPC и заданий из QuestieDB Forever, без
текстов заданий, координат и логики Questie. Когда маршрут содержит английское
имя, запись по ID дополнительно сверяется с этим именем. Поиск по английскому
имени допускается только при однозначном переводе.

Обычный Lua-аддон не выполняет HTTP-запросы к Wowhead или GitHub. Команда
`npm.cmd run names:update` скачивает данные вне игры и атомарно обновляет
локальный справочник. Сборка переносит его в аддон. Неизвестные уникальные
названия Forever запоминаются при получении от клиента.

Числовые ID сохраняются отдельно от отображаемых имён. Для активных шагов
отложенный поиск повторяется после открытия шага и при событиях клиента.
При смене шага попытки прекращаются. Обновление кнопок выбора цели
откладывается до выхода из боя. Портреты используют существующий механизм.

Проверки: безопасное чтение таблиц базы без исполнения Lua, сопоставление
имён и ID, приоритет клиента, сохранение кэша, отсутствие повторного ожидания
игрового события, остановка устаревших попыток и обновление после боя.
