# DiscodicXP · WoW Forever

Локальный аддон для клиента Forever 1.60.1, Interface 16001.
Основан на совместимом движке RestedXP 4.11.23. В игровом коде нет
проверки BattleTag, запроса BNGetInfo или зависимости кэша от аккаунта.

В комплекте русские элементы управления, тёмная тема с золотыми акцентами,
карта, стрелка, условия расы/класса и сохранение прогресса отдельно от RestedXP.
В личном интерфейсе убраны Discord, обратная связь и конфигуратор исходного
аддона. Импорт маршрутов и обычные настройки доступны как прежде.
Авторские пояснения купленного гайда сохраняются на исходном языке;
названия маршрутов переведены только для отображения, ключи переходов сохранены.

## Установка готовой сборки

Скачайте архив из [Releases приватного репозитория](https://github.com/Ishimitsu14/DiscodicXP-WoW-Forever/releases)
и скопируйте из него папку `DiscodicXP` в `Interface/AddOns` клиента Forever.
Для скачивания нужен доступ к репозиторию.

Для обновления одной кнопкой подготовлены Windows-лаунчер и собственный
HTTPS-сервис: он получает приватные сборки из GitHub, а игровой компьютер
подключается по отдельному ключу без GitHub-аккаунта. Перед использованием
нужно развернуть сервис и выдать ключ устройства.
Сборка, установка сервера и проверки: [docs/launcher.md](docs/launcher.md).
Автоматическая публикация лаунчера и SSH-настройки CI/CD: [docs/cicd.md](docs/cicd.md).

Для локальной сборки скопируйте папку `dist/DiscodicXP` в `Interface/AddOns` клиента Forever.
Она должна лежать непосредственно в AddOns, без дополнительной вложенной папки.
В списке модификаций отключите RestedXP Guides и включите DiscodicXP.
Если клиент был открыт во время установки, перезапустите его.

Либо из PowerShell:

```powershell
.\tools\install.ps1 -AddOnsPath 'E:\Games\World of Warcraft\_classic_beta_\Interface\AddOns'
```

Команды:

| Команда | Действие |
| --- | --- |
| `/dxp` | Настройки |
| `/dxp guides` | Выбрать маршрут |
| `/dxp import` | Импортировать или обновить гайд из текста файла |
| `/dxp show` / `/dxp hide` | Показать / скрыть |
| `/dxp status` | Текущий маршрут и шаг |
| `/dxp help` | Справка |

В сборку включаются стартовые маршруты установленного комплекта и 33 раздела
приложенного платного гайда: основной маршрут Орды 22–60 и AoE-маршруты мага.
Импортировать купленную строку в игре не нужно: гайды уже встроены.
Выберите подходящую своему персонажу ветку через меню маршрутов.

Под общим списком маршрута отображаются текущие шаги с галочками отдельных
пунктов. Задания отслеживаются автоматически; галочка позволяет вручную
отметить пункт в гайде. Блок «Выбор NPC» содержит кнопки выбора цели,
а не список выполнения заданий.

## Русские названия NPC и заданий

Аддон получает названия из клиента, сохраняет их в кэше и использует встроенный
русский справочник QuestieDB Forever, если клиент ещё не сообщил имя. Версия
0.3.0 содержит 9 073 NPC и 4 239 заданий. При наличии английского имени в
маршруте оно сверяется с записью базы; неоднозначные переводы не подставляются.
Для новых NPC Forever, отсутствующих в справочнике, остаётся исходное имя
из гайда. Русское название появляется после получения от клиента и сохраняется.
Поиск активных целей повторяется без ожидания встречи с NPC.

Прямые HTTP-запросы из Lua-аддона к Wowhead или GitHub недоступны. Русский
справочник обновляется на компьютере из открытых данных
[QuestieDB](https://github.com/Questie/QuestieDB), затем включается в сборку:

```powershell
npm.cmd run names:update
```

Команда обновляет `data/names.ruRU.json`, проверяя целостность источника. При
ошибке прежний справочник сохраняется. После этого соберите и установите
аддон командами ниже. Questie устанавливать не требуется. Портреты по-прежнему
получаются из выбранного NPC или NPC под курсором.

## Новый или обновлённый гайд внутри игры

1. Откройте `.txt` в Блокноте, нажмите Ctrl+A и Ctrl+C.
2. В игре вне боя введите `/dxp import` (также работает `/dxp импорт`).
3. Нажмите на поле «Содержимое файла» и вставьте текст через Ctrl+V.
   В окне показывается короткое превью, весь текст остаётся в буфере.
4. Для обновлений текущего купленного гайда оставьте имя файла пустым.
   Если другой файл не раскрывается, вставьте его полное исходное имя
   в поле «Имя исходного файла», включая часть после `!` и расширение `.txt`.
   Это локальная расшифровка файла, без запроса Battle.net и сверки с аккаунтом.
5. Нажмите «Импортировать / обновить» и дождитесь «Готово».
   Маршруты доступны через `/dxp guides` сразу, пересборка не нужна.

Совпадающие разделы заменяются; разделы с более старой версией пропускаются.
Повторный импорт одной версии обновляет содержимое без дубликатов. Прогресс
персонажа сохраняется, импортированные версии имеют приоритет над встроенными
после `/reload`. Повреждённый файл не заменяет существующие маршруты.
Для записи SavedVariables на диск после успешного импорта выполните `/reload`
или нормально выйдите из игры. Аддон также принимает открытый текст одного
маршрута с `#group`, `#name`, `step`; Lua-код из вставки не исполняется.

WoW не открывает произвольные файлы с диска: внутриигровая загрузка использует
вставку текста из файла, без диалога выбора файла в Проводнике.

## Повторная сборка

Нужен Node.js 22+. Сборщик читает исходный аддон и приложенный файл только локально.
Идентификатор из исходного имени используется для подготовки контейнера;
в игровую сборку записывается производный ключ для импорта обновлений.
Строка идентификатора и исходные пути в сборку и манифест не записываются.

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run names:update
npm.cmd run build -- --source '<путь к RXPGuides>' --guide '<исходный файл гайда.txt>' --output '<новая папка>\DiscodicXP'
npm.cmd run check -- '<новая папка>\DiscodicXP'
$env:DISCODICXP_BUILD = '<новая папка>\DiscodicXP'
npm.cmd test
```

Сборщик проверен с RestedXP v4.11.23 и останавливается на других версиях.
Он не перезаписывает существующую папку сборки. Установщик с `-Update`
обновляет аддон после резервного копирования в `dist/install-backups`:

```powershell
.\tools\install.ps1 -AddOnsPath '<Interface\AddOns>' -BuildPath '<новая папка>\DiscodicXP' -Update
```

`dist`, архив готового аддона и `UserGuides` содержат личный платный маршрут.
В историю Git они не включаются; готовые пакеты хранятся только в Releases
приватного репозитория.
Для публикации исходников используйте только `addon`, `tools`, `tests`, `docs`,
README, NOTICE и package-файлы. Готовую личную сборку публиковать открыто не следует.
`data/names.ruRU.json` — отдельная выгрузка названий QuestieDB для личной сборки;
источник и его точная версия указаны внутри файла.

## Проверки

`npm.cmd test` проверяет контейнер, повреждённые данные, синтаксис Lua 5.1,
граф TOC/XML, регистрацию 33 разделов без API аккаунта, парсер ветвлений
на нескольких сочетаниях класса/расы и команды интерфейса.
Тесты импорта проверяют расшифровку, обновление кэша, приоритет после перезагрузки,
отсутствие дубликатов, отмену и восстановление данных при ошибке.
Тесты названий проверяют приоритет клиента, сохранение кэша, сопоставление
источников и повторные попытки без игровых событий.
Проверка парсера использует заглушки игровых обработчиков команд: она не
подтверждает принятие/сдачу заданий или движение стрелки в реальном клиенте.

После установки проверьте в игре: выбор маршрута, принятие задания,
продвижение шага, стрелку и сохранение позиции после `/reload`.
